Operating core

  • sync.py with 6 PM rules enforced

02

Claude skills

Automated rituals. Your AI doesn't improvise — it obeys a protocol.

FAQ

Frequently asked

Do I need to know how to code?

No. The Install package is done-with-you. I handle all the technical parts. You just need to know how to use your Mac and Claude Code.

Does it work if I already use Notion / Asana / ClickUp?

Yes. The Ops Hack integrates with what you already have. You can keep Notion as your execution view — the system syncs bidirectionally. If you'd rather cancel Notion and save the monthly fee, it also works without.

What if I want to change something later?

All the code is yours from day 1. Modify whatever you want. If you need help, you can keep the $20/mo subscription or cancel anytime.

What does the $20/mo subscription include?

Everything new I ship: new skills auto-pushed to the template repo, sync.py improvements, Discord community access, weekly async Q&A, and a monthly group check-in call. If you cancel, you keep everything you already have.

Why Google Sheets and not a custom app?

Because it works. Sheets is free, you know it, it's reliable, and the API is solid. Building another app would reinvent the wheel. The value is in the discipline + enforcement, not the UI.
