Cómo funciona

4 capas que encajan

Cada capa resuelve un pedazo. Juntas son un sistema operativo completo.

01

Core operativo

El backbone. Un Google Sheet que es la biblia de todo tu trabajo.

  • Master Plan con 11 columnas estándar
  • Gantt automático + formato condicional
  • sync.py con 6 reglas PM enforced
  • Guard hook que bloquea escrituras manuales
02

Skills para Claude

Rituales automatizados. Tu AI no improvisa, obedece un protocolo.

  • /hi — check-in al empezar sesión
  • /bye — cierre limpio con sync a todos los sistemas
  • /mp-done — completar tarea + sync Calendar + Tasks
  • /sync-plan — reconciliar Sheet + Notion + Memoria
03

Memoria estructurada

Tu AI se vuelve más inteligente cada sesión. No olvida.

  • 4 tipos de memoria: user / feedback / project / reference
  • Feedback-as-rules: cada corrección se vuelve regla permanente
  • MEMORY.md como índice navegable
  • Frontmatter estándar en cada archivo
04

Integraciones

Todo tu stack actual, conectado y respetado.

  • Google Sheets · Calendar · Tasks · Gmail · Drive
  • Notion (opcional, bidireccional)
  • GitHub con CODEOWNERS + branch protection (si trabajás en duo)
  • Canva API (opcional)

FAQ

Preguntas frecuentes

¿Necesito saber programar?

No. El paquete Install es done-with-you. Yo hago toda la parte técnica. Vos solo necesitás saber usar tu Mac y Claude Code.

¿Funciona si ya uso Notion / Asana / ClickUp?

Sí. The Ops Hack se integra a lo que ya tenés. Podés mantener Notion como vista ejecutiva — el sistema sincroniza bidireccional. Si querés cancelar Notion y ahorrar el mes, también funciona sin.

¿Qué pasa si después quiero modificar algo?

Todo el código es tuyo. Modificás lo que quieras. Si necesitás ayuda, tenés 30 días de soporte incluido (60 en Duo), y después podés sumarte a la membership mensual.

¿Por qué Google Sheets y no una app propia?

Porque funciona. Sheets es gratis, lo conocés, es confiable, y la API está resuelta. Construir otra app sería reinventar la rueda. El valor está en la disciplina + enforcement, no en la UI.

¿Y si no me funciona?

Te devuelvo el 100% del dinero si a los 14 días me decís que no te sirvió. Sin drama.
